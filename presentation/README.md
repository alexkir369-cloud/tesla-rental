# Презентация проекта для Behance + фреймы для Figma

## Что внутри

| Файл / папка | Что это | Как использовать |
| --- | --- | --- |
| `VOLTA-RENT-behance.pdf` | 17 страниц, каждая — ровно **1440 × 1024 pt** | Импорт в Figma: `File → Place image` или перетащить PDF — Figma создаст **17 фреймов 1440 × 1024 px** |
| `frames/*.png` | Те же 17 слайдов в PNG **1440 × 1024** | Перетащить в Figma по одному, если нужен точный размер без импорта PDF |
| `behance-jpg/*.jpg` | Те же слайды в JPG **1400 × 996** | Готово к загрузке на Behance (лимит площадки — 1400 px) |
| `behance.html` | Исходник презентации (HTML + CSS, слайды 1440 × 1024, `zoom: 1.33` под печать) | Править текст/блоки, затем пересобрать PDF |
| `behance-frames.html` | Тот же документ без масштаба печати | Основа для PNG-кадров (каждый слайд вынесен в отдельный файл при сборке) |
| `shots/` | Скриншоты сайта и нарезки интерфейса, использованные в слайдах | Обновить и пересобрать |

## Как пересобрать

```bash
cd presentation
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

# PDF (17 страниц 1440×1024 pt)
"$CHROME" --headless=new --no-pdf-header-footer --virtual-time-budget=25000 \
  --print-to-pdf="VOLTA-RENT-behance.pdf" "file://$PWD/behance.html"

# PNG-кадры: каждый слайд выносится в отдельный файл, затем скриншот 1440×1024
# (см. шаги сборки в истории проекта или повторите вручную для нужных слайдов)
```

Размер страницы в PDF задаётся правилом `@page { size: 1920px 1365.33px; margin: 0 }`
(это ровно 1440 × 1024 pt) вместе с `body { zoom: 1.33 }`, поэтому фреймы в Figma
получаются 1440 × 1024 px, а вёрстка внутри заполняет их один в один.
